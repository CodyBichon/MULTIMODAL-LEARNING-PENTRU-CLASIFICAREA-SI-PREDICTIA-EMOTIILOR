# MULTIMODAL LEARNING PENTRU CLASIFICAREA ȘI PREDICȚIA EMOȚIILOR  
Prezenta lucrare propune o abordare multimodală pentru recunoașterea stărilor afective în contextul tehnologic al anului 2026, frecvent menționat în literatura de specialitate drept „anul multimodal" — un moment de maturitate al sistemelor capabile să proceseze nativ informații vizuale și auditive. Lucrarea dezvoltă și evaluează un sistem hibrid care integrează modalitățile vizuală și auditivă prin arhitecturi complementare și strategii de fuziune cu complexitate crescătoare, validate atât în condiții controlate cât și pe date externe nevăzute în antrenare.
